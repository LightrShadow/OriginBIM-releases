# OriginBIM downloads

Installers and updates for OriginBIM, the architectural modeller.

Download the latest version from the **Releases** page:

- `OriginBIM-Setup-<version>.exe` — installer (recommended; updates itself)
- `OriginBIM-Portable-<version>.exe` — runs without installing
